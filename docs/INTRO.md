# 什么是 TiphiaPress

![Tiphia](tiphia.png)

TiphiaPress 是一个以 Rust 后端和可拆分前端为核心的博客系统生态。它的目标不是简单复刻某个传统博客程序，而是提供一个适合现代前后端分离、插件化、主题化和长期维护的 Typecho 风格内容发布框架。

## 项目定位

TiphiaPress 由多个仓库组成：

- `tiphia`：核心后端。提供 REST API、认证授权、文章页面、评论、分类标签、插件系统、迁移系统、Docker 部署和 Typecho 迁移工具。
- `tiphia-frontend`：前端骨架。包含后台管理、博客前台、前端插件系统、前端 Hook、i18n 和主题加载约定。
- `tiphia-default-themes`：默认主题源码。主题可以独立维护，也可以通过 Git submodule 链接到前端仓库的主题目录。
- `tiphia-docs`：文档站。用于 GitHub Pages 发布。

## 核心理念

TiphiaPress 的设计重点是安全、高性能和可扩展。后端使用 Axum 与 SeaORM，提供结构化日志、统一错误响应、OpenAPI 文档和 Redis 限流。插件采用编译期集成方式，不做运行时动态加载，降低部署和安全风险。前端通过 Hook 和主题接口开放扩展点，让插件和主题都能以清晰边界参与页面渲染。

## 与传统博客系统的区别

传统博客系统通常把后端、后台、主题和插件放在同一个运行环境中。TiphiaPress 更强调拆分：

- 后端只负责数据、权限、插件后端逻辑和 REST API。
- 后台管理和博客前台由前端仓库构建，可以单独部署到 CDN 或静态服务器。
- 主题是前端模块，可以单独仓库维护。
- 插件可以同时包含后端插件和前端插件，两边通过 API、配置和 Hook 协作。

## 适合什么场景

TiphiaPress 适合希望拥有 Typecho 式轻量博客体验，但又希望项目结构现代化、API 优先、插件边界清晰、主题可独立维护的用户。它也适合开发者把它作为 Rust Web 框架、插件系统、前后端分离后台的参考模板。
